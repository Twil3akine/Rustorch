# Rustorch

Rustでテンソル演算と自動微分を実装した、小さな深層学習ライブラリです。外部の機械学習ライブラリは使わず、行列演算、誤差逆伝播、最適化、データ読み込みまでを一通り自前で実装しています。MNISTの手書き数字分類を題材に、学習から評価までを通して動かせます。

## 特徴

- テンソル型と自動微分（計算グラフによる誤差逆伝播）
- CPUバックエンドによる演算実装。バッチ化された行列積に対応します
- ニューラルネットワークの部品（Linear、ReLU、Sequential）
- 損失関数（交差エントロピー）と最適化手法（SGD、Adam）
- DataLoaderによるシャッフルとミニバッチ処理
- モデルの保存と読み込み（独自形式 `.rth`）
- 依存クレートは `rand` のみです

## 動作環境

- Rust（edition 2024に対応するバージョン）
- MNISTのデータは `data/mnist/` に同梱しています

## 使い方

学習済みモデルでテストデータを評価します。同梱の `mnist.rth` を読み込み、テスト精度を表示します。

```bash
cargo run --release -- eval
```

学習は次のコマンドで実行します。5エポック学習し、モデルを `mnist.rth` に保存したうえで、テスト精度を表示します。

```bash
cargo run --release -- train
```

引数を省略した場合は `eval` として動作します。

## 結果

同梱の学習済みモデルで、MNISTのテストデータ10,000件に対する精度は **97.75%** でした（2026年11月に実測）。`train` コマンドで学習を再実行した場合も、テスト精度は97.08%となり、近い結果が再現できました。

モデルは784入力、隠れ層128、10出力の多層パーセプトロンで、最適化にはAdam（学習率0.001、バッチサイズ128）を使っています。

## テスト

```bash
cargo test
```

テンソル演算、自動微分、最適化などのユニットテストが31件あります。

## 構成

- `src/tensor.rs`: テンソル型と演算
- `src/autograd.rs`: 自動微分
- `src/backend/`: CPUバックエンド
- `src/nn/`: ニューラルネットワークの部品と損失関数
- `src/optim/`: 最適化手法（SGD、Adam）
- `src/data/`: データセットとDataLoader、MNISTの読み込み
- `src/model_io.rs`: モデルの保存と読み込み
- `src/main.rs`: 学習と評価の入口
